## Upstream projects

FullDex builds upon and incorporates components from independent open-source projects, including:

- [ClickingMaster/ssrecomp](https://github.com/ClickingMaster/ssrecomp) — original project from which this repository was forked.
- [melonDS](https://github.com/melonDS-emu/melonDS) — Nintendo DS emulator.
- [PokeDaisy](https://github.com/lidor30/pokedaisy) by Lidor Itzhari — adapted companion readers and text decoders.
- [mGBA](https://mgba.io) — Game Boy Advance emulator.
- Other projects and contributors acknowledged in the README and associated licence files.
